---
name: handoff
description: Generate session handoff before ending. Use when context is filling up.
---
Create .claude/session-handoff.md with:
1. Goal - what we were trying to do
2. Completed - exact file paths changed
3. Decisions - key choices and why
4. In progress - half-done work
5. Next steps - exact first 2-3 prompts for next session
6. Blockers - things needing human input
Under 80 lines. Specific paths only.
